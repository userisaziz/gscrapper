How it works

Draw an area. Get a spreadsheet.

MapReach grids your search area, queries Maps like a browser would, then visits each business site to find an email — all locally, all in one pass.

leads_austin_coffee.csv
$ mapreach scan --area "Austin, TX" --category "coffee shop"

FAQ

Good to know

Does MapReach need a Google API key?

No. MapReach reads results the same way a browser would, so there's no API key to manage and no per-request billing from Google.

Where does my scan data go?

Nowhere but your machine. Scans run locally and export straight to a CSV file on your disk — MapReach's servers never see your results.

Can I cancel anytime?

Yes. The plan is month-to-month with no contract. Cancel and you simply lose access at the end of your billing period.

Which platforms are supported?

Windows 10/11, macOS 12+ (Intel and Apple Silicon), and Linux via AppImage — download links are in the hero above.

Is the source code available?

Yes, MapReach is open source. You can read the code, file issues, or self-build it from the GitHub repository linked in the footer.
