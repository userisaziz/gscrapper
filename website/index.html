Installation Help

The app is not code-signed — your OS may show a security warning. Here's how to proceed safely.

🍎 macOS

  1. Open the .dmg and drag the app to Applications.
  2. When you see "Apple could not verify…", click Cancel.
  3. Go to System Settings → Privacy & Security.
  4. Scroll down and click "Open Anyway".
  5. Confirm by clicking Open.

Or run in Terminal (after moving to Applications):

xattr -cr /Applications/Google\ Maps\ Scraper.app

🪟 Windows

  1. Run the .exe installer.
  2. When SmartScreen shows "Windows protected your PC", click "More info".
  3. Click "Run anyway" at the bottom.
  4. Proceed with installation as normal.

🐧 Linux

  1. Make the AppImage executable:
chmod +x Google-Maps-Scraper-*.AppImage
  1. Run it:
./Google-Maps-Scraper-*.AppImage
  1. If blocked, right-click → Properties → Permissions → check "Allow executing as program".
